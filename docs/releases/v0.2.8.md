# v0.2.8

## Highlights

- Persistent diagnostics logging with one-tap export.
- Much more resilient storage and downloads when a removable SD card is slow, missing, or returns.
- Streamed audio now lives on internal storage; the SD card is used only for explicit downloads.
- Artist and album pages can now show content from other sources.

## Diagnostics

- Verbose diagnostics are written to bounded, app-private JSONL logs in all builds.
- Logs cover app lifecycle, HTTP failures and timings, auth, connectivity, playback,
  Media3 internals, cache activity, downloads, storage, and Android Auto.
- Crashes, ANRs, low-memory kills, and process-exit reasons are captured and survive
  restarts.
- Settings → Diagnostics can change the logging level, export a zip to Downloads, and
  clear logs.
- Cookies, auth headers, request bodies, URL queries/userinfo, and sensitive JSON values
  are redacted.

## Storage and downloads

- Completed download metadata is no longer deleted when the Media3 index is empty or
  unavailable; missing files become retryable instead.
- Settings and Downloads no longer freeze while reading storage or cache on a slow SD
  card.
- A storage-health banner explains when the selected volume is unavailable or changed,
  with a restart action.
- Downloaded tracks fall back to streaming when the download volume is unhealthy and
  the phone is online.
- Playback now times out visibly instead of loading indefinitely when storage or the
  resolver stalls.
- Streamed audio moved to internal storage with a 512 MB LRU budget. Downloads remain
  on the selected volume.
- Download indexes and caches are separate, and the download cache opens lazily.
- Changing download storage keeps the internal streamed cache; changing server clears
  both caches.
- Old streamed spans left in the download cache are cleaned up automatically.

## Artist and album pages

- Added “From other sources” content for artists and albums.
- UUID entities show source tabs; identity entities load their single source directly.
- Artist content shows an albums shelf and tracks; album content shows the source
  tracklist.
- Ephemeral tracks are playable, queueable, savable, and download individual tracks
  through the track context menu.
- Ephemeral artists and albums can be saved (identity saves are save-only because the
  API has no identity unsave).
- Adding an album to a playlist now adds the album entity, matching the web client.
- Ephemeral albums do not show an album-level download button.

## Quality

- Added coverage for ephemeral content APIs, identity keys, artist source selection,
  storage reconciliation/labels, cache/file logging, and redaction.
- Pinned a stable local debug signing key so debug installs stop changing certificates,
  and documented the one-time uninstall needed when a debug key is lost.
