# v0.2.9

## Fixes

- Fixed a crash introduced in v0.2.8 where the playback watchdog read
  `ExoPlayer` state from a background coroutine, triggering
  `IllegalStateException: Player is accessed on the wrong thread`.
- The watchdog now performs its player-state check and pause action on the main
  thread.

**Full Changelog**: https://github.com/eyezahhhh/pipe-bomb-android/compare/v0.2.8...v0.2.9
